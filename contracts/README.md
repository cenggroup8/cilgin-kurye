# Shared contracts

These files are the agreements between modules. Every module may read them;
nobody changes them alone. A change needs a pull request with the `contracts`
label, approval from each module that uses the file, and a new version number.

| File | Used by | Owner |
| --- | --- | --- |
| `city_plan.json` | M1, M3, M4, M6 | M1 (M6 reviews) |
| `board_protocol_vectors.json` | M2, M6, tools | M6 |
| `messages.md` | M1–M6 | M1 and M2 |

Both JSON files are generated by scripts in `tools/`. Edit the script, not the JSON.

## Coordinates

- World units: metres, seconds, degrees.
- Origin at intersection `n_0_0` (north-west corner). x to the east, z to the south, y up.
- Heading in degrees, clockwise from north.
- Board coordinates: `u = x / size_m`, `v = z / size_m` (0 to 1).

## ID rules

The city has a 6 × 6 grid of intersections and 60 road segments.
IDs come from formulas, so no module needs a lookup table.

| Item | Name | ID |
| --- | --- | --- |
| Intersection, row r, column c (0–5) | `n_r_c` | `6r + c` (0–35) |
| East–west segment from `n_r_c` to `n_r_(c+1)` | `h_r_c` | `5r + c` (0–29) |
| North–south segment from `n_r_c` to `n_(r+1)_c` | `v_r_c` | `30 + 6r + c` (30–59) |
