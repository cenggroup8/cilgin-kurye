# M5 Player Client and 3D City

Phone web page: low-poly 3D city (Three.js), controls, compass, "Find me" button, team selection.
Players join with a QR code; nothing is installed on the phone.

Members: Abdullatif Yılmaz, Berk Andaçgil, Selim Barut

Uses `contracts/city_plan.json` to build the city, so it always matches the LED board.
